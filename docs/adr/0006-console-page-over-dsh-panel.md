# 独立控制台网页取代 DSH 面板成为主 UI

修订 [0003](0003-dsh-panel-ui.md)：运营者的主界面改为独立网页「控制台」——仓库内 Node/TS sidecar 服务于 127.0.0.1:3083（静态页 + 代理 `/orchestrator/api` + 后续平台接线的文件协议编排），信息架构参考原 Easel 前端；DSH 内置面板保留存量、不再投入。控制台同时是第二个 Source（kind `console`），可在页面上发起请求与发布把关确认，与飞书双通道并存。0003 弃 Web 工作台的理由（两套 UI 维护面大）被两点新事实压过：平台能力要全部接上、需要一个承载面；DSH 无头后台运行需要不依赖宿主 UI 的入口。Easel 的 Web 前后端代码仍不迁移——账号/发布/归因通过文件协议复用技能脚本，而非移植 5681 行单体。
